# AudioShare USB v3.0.0-rc.1

First public hardware-tested release candidate of the Windows-to-Android USB
audio fork.

## Included

- Captures all ordinary Windows system audio using global process-loopback mode,
  with bounded multi-endpoint and default-output compatibility fallbacks.
- Streams 48 kHz stereo PCM16 over an authenticated, USB-only ADB forward.
- Installs and verifies the matching permanently signed Android companion with
  one explicit action.
- Automatically supervises an authorized physical USB phone, with bounded retry
  and exact forward/session cleanup.
- Exposes host queue, transport, Android buffer, route, focus, drop, underrun,
  endpoint, and heartbeat diagnostics.
- Requires no LAN, Wi-Fi, Internet, firewall rule, virtual audio driver, Windows
  service, or administrator elevation at runtime.

## Hardware evidence

The initial Galaxy A52s / Android 14 run completed companion installation and
audible global-system playback with a 10 ms host queue high-water mark, 10 ms
heartbeat round-trip time, and zero visible host/Android drops.

## Release-candidate limitations

Ten-minute screen-off endurance, repeated USB recovery, measured median/p95
latency, restricted-PC behavior, and the two-hour run remain manual stable-release
gates. The Windows executable is not Authenticode signed, so Microsoft SmartScreen
may show an unknown-publisher or reputation warning.

Download the Windows ZIP, verify its adjacent SHA-256 file, extract the complete
archive to a user-writable directory, enable USB debugging on the phone, and run
`audioshare.exe` as a normal user. If prompted, choose **Install companion** once.
